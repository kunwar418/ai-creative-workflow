# AI Product Creative Generation Workflow

## Setup

1. Install Python 3.10+
2. Install Ollama from https://ollama.com/download/windows
3. Run: `ollama pull llama3.2`
4. Run: `pip install -r requirements.txt`
5. Run: `python main.py`

## Features

- Extract product info from URLs
- Generate 5 product images
- Generate 2 product videos
- Bulk CSV processing
- Quality review with scoring
